# How it Works {#how-it-works}

## The Bond Journey

### 1. Welcome & Onboarding
When you and your partner first join Bond, we start with a warm welcome and non-judgmental setup:
- **Quick intro**: Learn what Bond offers and how to get the most from it
- **Onboarding assessment**: A short, friendly assessment to understand your relationship
- **Profile setup**: Create your couple profile and define what "stronger relationship" means to you
- **Privacy assurance**: We explain how your data is protected and never shared externally

### 2. Couple Assessments
Bond uses evidence-based assessments to reveal patterns and opportunities:

**The Relationship Health Assessment**
- Evaluates 7 core dimensions: Communication, Trust, Intimacy, Conflict Resolution, Shared Values, Emotional Support, and Fun & Adventure
- Takes 15-20 minutes to complete (each partner completes separately)
- AI compares responses to identify alignment and gaps
- Visual results show where you're strong and where you might grow

**Specialized Assessments**
- **Intimacy Audit**: Explores physical and emotional intimacy (optional, premium)
- **Conflict Patterns**: Identifies how you disagree and where misunderstandings happen
- **Values Alignment**: Compares life goals, priorities, and vision for the future
- **Love Language Check-In**: Discover how each partner prefers to give and receive affection

### 3. AI Insights & Reflections
After assessments, you get personalized AI insights:
- **Couple-specific analysis**: "Based on your responses, here's what we're noticing..."
- **Pattern recognition**: Highlights recurring themes in how you communicate
- **Celebration of strengths**: Specific praise for what's working well
- **Growth opportunities**: Gentle suggestions for deepening connection
- **Conversation starters**: Questions designed to spark meaningful dialogue

### 4. Shared Learning Library
Bond offers guided learning in 4 core areas:

**Communication Mastery**
- How to express needs without blame
- Active listening techniques
- De-escalation during conflict
- Repair attempts and reconnection

**Emotional Intimacy**
- Building vulnerability and trust
- Understanding attachment styles
- Emotional attunement
- Creating safety in the relationship

**Conflict Resolution**
- Healthy disagreement frameworks
- From argument to understanding
- Problem-solving as a team
- Forgiveness and moving forward

**Fun & Connection**
- Date night reimagined
- Playfulness and laughter
- Adventure and novelty
- Shared experiences that deepen bond

### 5. Guided Activities & Exercises
For every learning topic, Bond offers structured activities:
- **20-minute exercises**: Timed, step-by-step activities you do together
- **Discussion prompts**: Questions to explore together (conversation-starter cards, video prompts)
- **Creative projects**: Things like creating a shared vision board or timeline of your relationship
- **Experience suggestions**: Ideas for dates, adventures, or intimate moments

### 6. Progress Tracking & Reflection
As you work through learning and activities, Bond tracks your progress:
- **Dashboard**: See which topics you've explored, which you're working on
- **Reflection prompts**: "What did you notice about each other this week?"
- **Growth markers**: Celebrate milestones ("You've completed 5 communication exercises!")
- **Relationship health trends**: Visual tracking of how your relationship is evolving

### 7. Premium Insights (Paid)
With premium, you get:
- **AI journal analysis**: Optional AI analysis of your private couple journal (with consent)
- **Weekly couple briefings**: AI-generated summary of the week's interactions and suggested focus
- **Deep-dive insights**: More detailed assessment results and personalized recommendations
- **Priority support**: Faster response times if you have questions

### 8. Always Optional, Never Forced
Bond is designed around **full autonomy**:
- **No mandatory sequences**: You choose what to explore and when
- **Pause anytime**: Take breaks without judgment
- **Customize your path**: Focus on topics that matter most to you
- **Respect boundaries**: Some couples want deep dives; others prefer broad overviews. Both are OK.

# Learning Library {#learning-library}

## Comprehensive Relationship Education

The Bond Learning Library is designed by relationship experts and organized around 4 core pathways plus specialized deep-dives.

### Core Learning Pathways

#### 1. Communication Mastery
Master the fundamentals of expressing yourself and truly hearing your partner.

**Topics Covered:**
- The 4 horsemen of the apocalypse (criticism, contempt, defensiveness, stonewalling) and their antidotes
- Nonviolent Communication (NVC) framework
- Active listening: hearing vs. understanding
- "I" statements and responsibility talk
- Asking for what you need without blame
- Reflection and validation techniques
- Repair attempts during conflict
- Building vocabulary for emotions

**Video Lessons:**
- "Why We Hear Criticism as Contempt" (10 min)
- "Active Listening Isn't What You Think" (12 min)
- "The Power of 'Yes, and...'" (8 min)
- "De-escalation Techniques That Actually Work" (15 min)

**Exercises:**
- Structured listening practice (you listen, partner shares; then swap)
- Gratitude rounds (expressing appreciation systematically)
- Complaint → Request translation (turn complaints into solvable problems)
- Repair conversation blueprint (practice reconnection)

#### 2. Emotional Intimacy & Connection
Deepen emotional closeness and create safety for vulnerability.

**Topics Covered:**
- Attachment styles: Secure, anxious, avoidant, fearful
- How attachment plays out in relationships
- Building psychological safety
- Vulnerability and courage
- Trust and repair after breach
- Emotional attunement and empathy
- Appreciation and celebration
- Creating rituals of connection

**Video Lessons:**
- "Understanding Attachment Styles" (15 min)
- "The Neuroscience of Intimacy" (12 min)
- "Vulnerability Isn't Weakness" (10 min)
- "Creating Safety in Your Relationship" (13 min)

**Exercises:**
- 36 Questions to Fall in Love (modified for established couples)
- Eye contact and silent presence (10 min of non-verbal connection)
- Appreciation ritual (structured gratitude practice)
- Share a vulnerable moment (guided conversation prompt)

#### 3. Conflict Resolution & Problem-Solving
Turn disagreements into opportunities for deeper understanding.

**Topics Covered:**
- Healthy vs. unhealthy conflict
- The Gottman method for conflict
- Problem-solving frameworks (principled negotiation, interest-based, etc.)
- Compromises vs. solutions
- Forgiveness and moving forward
- When to call in outside help
- Patterns of conflict and de-escalation
- Creating agreements you both can keep

**Video Lessons:**
- "Why Conflict Isn't the Enemy" (8 min)
- "From Argument to Understanding" (14 min)
- "The Gottman Repair Checklist" (9 min)
- "Apology & Forgiveness Roadmap" (11 min)

**Exercises:**
- Gentle start-up practice (beginning a difficult conversation)
- Issue → Core concern mapping (dig to root causes)
- Compromise vs. solution brainstorm
- The apology conversation (structured, step-by-step)

#### 4. Fun, Adventure & Connection
Keep the spark alive and create shared joy.

**Topics Covered:**
- Novelty and its role in relationship satisfaction
- Date nights that actually matter
- Play and humor in relationships
- Shared goals and adventures
- Spontaneity and surprise
- Celebrating each other
- Creating couple traditions
- Sex and physical affection

**Video Lessons:**
- "Why Date Nights Don't Work (And What Does)" (10 min)
- "The Power of Playfulness" (8 min)
- "Sexual Desire and Emotional Connection" (15 min, mature audiences)
- "Building Your Couple Vision" (11 min)

**Exercises:**
- Adventure bucket list creation (dream together)
- Date night design sprint (plan something intentional)
- Playfulness challenge (5 ways to laugh together this week)
- Gratitude + celebration (acknowledge your partner publicly)

## Frequently Asked Questions

**Can we try Premium before committing?**
Yes! We offer a 7-day free trial with full Premium access. No credit card required to start.

**Can I pause my subscription?**
Yes. You can pause for up to 3 months. Your data is saved, and you can resume anytime.

**What if we don't use it?**
We have a 30-day money-back guarantee. If you're not seeing value, we'll refund your first month, no questions asked.

**Is it really couple-specific?**
Yes. Every assessment, exercise, and piece of content is designed with couples in mind (not individual therapy adapted for two people).

**What happens if we break up?**
Your account data is yours. You can download everything, or delete it. No judgment.

**Do you offer couples counseling?**
No, Bond is **not therapy**. We're a learning and connection platform. If you need professional help, we can point you toward resources.

**Is my data private?**
Completely. We use end-to-end encryption, and we never sell or share your data. Bond is not a HIPAA-covered service today; the clinician features are built to support HIPAA technical safeguards, but compliance has not been established.

## Repo Layout

- `mobile/` — Expo/React Native app. This is the product; every real user-facing screen lives here. See `mobile/CLAUDE.md`.
- `backend/` — FastAPI thin services layer (AI insights, the four text analyzers, Stripe billing). Not a general CRUD API — the mobile app talks to Supabase directly for everything else.
- `frontend/` — Create React App scaffold. Vestigial; has no Bond-specific screens. See `frontend/README.md`.
- `supabase/` — Postgres schema, migrations, seeds. `supabase/bond_schema.sql` is the canonical source of truth for current tables (not the `migrations/` folder, which is incomplete).
- `clinician-web/` — Next.js 14 clinician/institutional dashboard (migration 021). See `clinician-web/README.md`.

Full product/architecture requirements live in `PRDs'/` — read `PRDs'/00_Master_Index-1.md` first. See the repo-root `CLAUDE.md` for the full set of binding project rules.

## Running Each Component

### Mobile (`mobile/`)

```bash
cd mobile
npm install
npm start          # Expo dev server
npm run ios        # or npm run android / npm run web
npm run lint
npm run type-check
npm test
```

### Backend (`backend/`)

```bash
cd backend
pip install -r requirements.txt
cp .env.example .env   # fill in Supabase, Anthropic, and Stripe credentials
uvicorn server:app --reload
make check          # black + isort + flake8 + mypy
make test            # pytest
```

### Clinician dashboard (`clinician-web/`)

```bash
cd clinician-web
npm ci
cp .env.example .env.local   # Supabase URL, anon key, service-role key (audit writes only)
npm run dev
npm run type-check && npm run lint && npm test && npm run build
```
